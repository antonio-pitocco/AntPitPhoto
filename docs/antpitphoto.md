# AntPitPhoto

AntPitPhoto is AntPitLab's build of [LightCraft](https://github.com/storytold/lightcraft)
(MIT OR Apache-2.0), tuned for preparing fine-art exhibition prints and their web versions.
It is an independent fork: not affiliated with or endorsed by the LightCraft or ArtCraft authors.

*AntPitPhoto è la versione di LightCraft di AntPitLab, pensata per preparare stampe fine-art da
mostra e le loro versioni web.*

## What it adds to LightCraft

- **Italian interface** (`crates/ui-egui/locales/it.json`, `it-formats.json`; Edit ▸ Language ▸
  Italiano). The app built by `packaging/macos/antpitphoto-local.sh` starts in Italian.
- **«Mostra» export presets** (File ▸ Export with Preset):
  - lab print, TIFF 16-bit Adobe RGB, 300 ppi, full resolution, matte-paper sharpening;
  - the same for baryta paper (glossy sharpening);
  - 40×60 cm print with a 5 cm paper border (6 cm at the bottom);
  - web gallery, JPEG sRGB 2560 px, quality 85, 4:4:4, screen sharpening, no GPS.
- **Print size in centimetres** — `printCm` in `app.export`: a number (long edge in cm) or
  `[width, height]` in cm (the photo fits the box in either orientation), at the export `ppi`.
  It is an exact size: it upsamples when needed.
- **Printed paper border / mat** — `border`: centimetres on every side, or
  `{cm, bottomCm?, gray?}` (heavier bottom border; `gray` 0–255, 255 = paper white). It is added
  after sharpening and watermark, outside the picture; the picture keeps the size asked for.
- **No hidden cap on headless print exports**: without a size, `lightcraft-cli run … app.export`
  used to write 3000 px even for a 16-bit TIFF at 300 ppi (a 25 cm print instead of 80). 16-bit
  TIFF/PSD, files with `ppi` or with a border now export at full resolution.
- **Name and icon**: the macOS app is `AntPitPhoto.app` (bundle id `it.antpitlab.antpitphoto`)
  with its own icon (`assets/app-icon/antpitphoto/`, regenerated by
  `packaging/macos/antpitphoto-icons.sh`): a print with its exhibition mat, in the 3:2 frame,
  where the shadows glow amber and the light dissolves into lavender.

Libraries, presets and settings stay LightCraft's: AntPitPhoto opens the same libraries.

## Build and install (macOS, Apple silicon)

```sh
export CARGO_TARGET_DIR=/a/disk/with/space/lightcraft-target   # the build needs ~15 GB
bash packaging/macos/antpitphoto-local.sh        # build, ad-hoc sign, install in /Applications
bash packaging/macos/antpitphoto-local.sh --skip-build --no-install   # package only
```

The app is signed ad hoc for the Mac that builds it; other Macs' Gatekeeper refuses it.

## Examples

```sh
# TIFF for the lab, 40×60 cm at 300 ppi, 5 cm border (6 at the bottom)
antpitphoto-cli run --library LIB app.export '{"ids":[1],"preset":"Mostra: stampa 40×60 cm con bordo carta 5 cm (TIFF 16 bit Adobe RGB, 300 ppi)","dir":"OUT"}'
# Lightroom presets (.xmp) are imported as they are, colour grading included
antpitphoto-cli run --library LIB preset.import '{"paths":["PRESETS/MyLook"]}'
```

## Known limits (from LightCraft)

- No Print module and no conversion to a paper+printer ICC profile on export: soft proofing with
  the paper profile is there (View ▸ Soft Proof, S); the lab does the conversion.
- The border is not drawn in the preview: it is only in the exported file.
